# Launcher social-media images

Three 1600 × 1200 PNG cards (4:3), with matching self-contained SVG sources.
The green radial gradient, 40-pixel mesh grid and outlined Tux-Force logo come from the website brand assets.
Each card embeds a redacted GUI screenshot at its original 1240 × 800 resolution.

- [Library](launcher-library-social.png) · [SVG source](launcher-library-social.svg)
- [Store](launcher-store-social.png) · [SVG source](launcher-store-social.svg)
- [Game details](launcher-detail-social.png) · [SVG source](launcher-detail-social.svg)

Account details and personal paths are redacted. The detail screenshot also masks runtime logs.
Only sanitized images are embedded in the SVGs. Original captures are excluded.

Unofficial community project. Not affiliated with Microsoft or Xbox. Game artwork belongs to its respective owners.
